# 1.20.1 Forge 参考依赖

本文件只记录开发运行环境中的参考模组，不代表最终发布包的必需依赖。参考依赖用于检查本附属面对大量材料、工具部件和模块化物品时的兼容性。

| 模组 | CurseForge 项目 | 文件 ID | 用途 |
| --- | ---: | ---: | --- |

## 选择依据

Tinkers Reforged 的 1.20.1 文件包含 slime bronze、graphite、yttrium、astatine、barium、tellurium、actinium、thallium、germanium 和 berkelium 等材料，适合验证材料 ID、部件材料和词条扫描逻辑。

## 后续兼容性检查重点

1. 材料与部件注册是否只依赖匠魂注册表，不把其他模组的物品 ID 写死。
2. KubeJS 脚本加载顺序变化时，材料、词条和配方事件是否仍能重复执行而不重复注册。
3. 匠魂工具和普通物品之间的标签判断是否互相污染。
4. 参考依赖缺失时，附属是否能通过条件加载保持基本启动能力。
